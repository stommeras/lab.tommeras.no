Planen er å skrive [sandsimuleringen](/sand/) om til Rust og kjøre den i nettleseren som WebAssembly. Først skal den oppføre seg nøyaktig som TypeScript-versjonen. Så blir rutenettet større, og det kommer nye materialer: olje som flyter på vann, tre som brenner, ild, røyk, damp og lava.

Ikke bygget enda.
